# FoodGaurd - Product Ingredient Analysis

A modern AI-powered food ingredient and nutrition analysis web application.

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Lucide React Icons
- Geist Font

## Features

- Product Scanner (barcode + ingredient capture)
- Ingredient Analysis with assessment levels
- Nutrition Details
- Evidence & Sources tracking
- Search Alternatives
- Product History
- User Profile & Personalization
- Dark / Light mode
- Admin Dashboard
- English & Hindi localization

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Deployed on [Vercel](https://vercel.com)
